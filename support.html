Window Engine Support

Last updated: 2026-11-21

Support hub: Steam Community Discussions

Before posting

  • Use Windows 10 22H2 or Windows 11, 64-bit.
  • Set target applications to windowed or borderless window mode. Exclusive fullscreen cannot be previewed or arranged.
  • If Steam verification is requested, start Steam, sign in with the purchasing account, and launch Window Engine from Steam.
  • After a successful verification, offline use is allowed for up to 30 days.

Logs and settings

  • Settings: %APPDATA%\WindowEngine\settings.json
  • Logs: %APPDATA%\WindowEngine\logs\
  • Offline license: %LOCALAPPDATA%\WindowEngine\steam-license.dat

When reporting a problem, include the app version, Windows version, and the latest log file. Do not post your Steam password or Steam Guard codes.

Common issues

  • Preview is black or unavailable: switch the renderer to PrintWindow in settings, or check whether the target window is minimized.
  • Hotkeys do not work: another application may have registered the same combination; change the hotkey in settings.
  • Startup without Steam: the app needs one successful Steam ownership check, then it can start offline for 30 days.
  • Steam Cloud conflict: portable settings sync by timestamp. If two PCs changed settings at the same time, the newer copy wins.
